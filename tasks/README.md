# PixelGleam Codex Tasks

Lifecycle:
- `backlog/` — identified but not ready/active
- `active/` — approved for execution
- `review/` — implementation finished, awaiting root review
- `done/` — root accepted

Workers do not move their own work to `done/`.

Each coding task should be bounded and include:
Goal / Relevant files / Required behavior / Must not change / References / Acceptance criteria / Tests / Return report.
