# AI Studio Phase Report Template

Every implementation phase must end with exactly this type of report:

```text
STATUS: PASS / REWORK / BLOCKED

Implemented:
- ...

Preserved:
- ...

Files changed:
- ...

Tests executed:
- ...

Gameplay QA:
- ...

Visual QA:
- ...

Known deviations:
- ...

Acceptance gate:
- PASS/FAIL per criterion

Next phase:
- ...
```

If any P0 criterion fails, status cannot be PASS.
