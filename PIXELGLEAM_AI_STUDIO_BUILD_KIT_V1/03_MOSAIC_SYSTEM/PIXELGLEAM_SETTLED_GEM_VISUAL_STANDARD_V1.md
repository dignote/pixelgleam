# PixelGleam Settled Gem Visual Standard V1

## Goal
The completed artwork must feel like a premium gem/bead mosaic, not a rigid pixel grid and not a smooth ordinary illustration.

## Target position

```text
rigid square pixel grid  <---- TARGET ---->  completely smooth illustration
```

PixelGleam sits near the middle-right: soft silhouette and authored shading, while individual mosaic/gem material remains perceptible.

## Required visual properties
- organic small mosaic pieces or bead/gem microstructure,
- subtle facets/highlights,
- restrained micro-seams,
- contours follow the artwork rather than a global square lattice,
- stable visual scale across artwork,
- neutral UI so artwork remains dominant.

## G02 relationship
G02 is an animation/feedback material reference. The settled texture does not need to stamp the exact G02 sprite at every cell.

The visual family must remain cohesive:
- similar highlight logic,
- similar polish/material feeling,
- compatible color treatment,
- similar tactile jewel identity.

## Do not
- render a flat cartoon illustration with no visible mosaic character,
- create thick black cell outlines everywhere,
- use equal square cells across all forms,
- create large transparent gaps between settled pieces,
- allow particle/glow effects to hide the artwork.

## Completion transition
Recommended sequence:

```text
region accepted logically
→ selected cells/region indicate activation
→ limited G02 gems travel toward target area
→ landing snap / tiny settle
→ settled texture region reveals
→ restrained sparkle/pulse
```

The final reveal must remain correct if animations are skipped or interrupted.
