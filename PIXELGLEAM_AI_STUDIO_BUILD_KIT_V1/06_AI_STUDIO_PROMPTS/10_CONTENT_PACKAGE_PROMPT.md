# Prompt 10 — Scalable Artwork Package Integration

Implement content loading so new compiled artwork packages can be added without editing gameplay engine logic.

The app must consume the frozen content contract generated by Mosaic Topology Compiler V1.1:
- metadata/artwork JSON,
- Cell-ID raster,
- subject/void topology as available,
- settled texture,
- thumbnail/palette metadata.

Use B2–B5 only as content-contract/benchmark references unless they have complete compiler outputs included in the supplied compiler package.

Do not run the topology compiler on-device.
Do not run AI segmentation on-device.
Do not infer regions from the settled image.

Add validation/error handling for malformed artwork packages.

End with phase report.
