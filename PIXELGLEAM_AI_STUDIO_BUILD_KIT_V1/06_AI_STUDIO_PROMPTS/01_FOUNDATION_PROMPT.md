# Prompt 01 — Android Foundation

Implement only Phase A1 from the approved plan.

Use native Android with Kotlin and Jetpack Compose unless the existing project already has a stable compatible native architecture that should be preserved.

Create only the minimum production foundation needed for the PixelGleam vertical slice:
- app/module structure,
- navigation foundation,
- lifecycle-safe state holder boundaries,
- local content loading interface,
- persistence interfaces/storage foundation,
- resource organization,
- test scaffolding.

Do not implement broad UI screens yet.
Do not add cloud, account, leaderboard, shop, currency, analytics, achievements, ads mockups or any unimplemented online feature.
Do not create a general game engine, ECS, physics engine or custom render thread.

The project must compile and launch.

End with the required PASS / REWORK / BLOCKED phase report and list every file changed.
