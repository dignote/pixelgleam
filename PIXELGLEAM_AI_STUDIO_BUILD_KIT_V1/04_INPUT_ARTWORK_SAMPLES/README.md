# Artwork Benchmark Inputs

These four images were generated as benchmark masters for testing the content pipeline across different shape families.

- `B2_FLOWER_MASTER.png` — floral / botanical, overlapping petals/leaves and gaps.
- `B3_MANDALA_MASTER.png` — symmetric ornamental geometry; difficult thin/elongated regions.
- `B4_CUPCAKE_MASTER.png` — food/object with broad curved bands and small decorations.
- `B5_CHARACTER_MASTER.png` — character anatomy, hair, limbs, prop and negative spaces.

They are useful for validating input normalization, masks and compiler behavior. They are not automatically store-production content without an explicit art approval pass.
