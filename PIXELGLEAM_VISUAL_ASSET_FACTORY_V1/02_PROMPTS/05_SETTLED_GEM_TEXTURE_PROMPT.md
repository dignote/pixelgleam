# Settled Gem Texture Authoring Prompt

Transform the approved PixelGleam illustration into its completed gem-mosaic appearance.

Preserve the exact subject, pose, color intent, facial readability, composition and negative spaces.

Material: Soft Faceted Resin Gem.

Use:
- small organic mosaic units aligned with the form
- restrained facet highlights
- subtle seams between units
- soft tactile depth
- coherent material response
- slightly varied organic cell rhythm

Avoid:
- square pixel lattice
- stamped hex texture everywhere
- stained-glass black grout
- random geometry crossing semantic boundaries
- gems inside background/negative space
- excessive sparkle or casino jewelry appearance
- smoothing the artwork so much that the mosaic units disappear

The final should clearly read as a premium gem/bead mosaic while retaining soft contours.
