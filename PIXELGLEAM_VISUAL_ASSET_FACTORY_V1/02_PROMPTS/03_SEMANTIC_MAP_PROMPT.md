# Semantic Map Authoring Prompt

Using the approved artwork as reference, create a flat semantic-color source map for gameplay preparation.

Requirements:
- flat colors only
- no shading, glow, texture or antialias ambiguity
- preserve exact subject silhouette and meaningful negative spaces
- group decorative highlights/shadows into the nearest intentional semantic color where reasonable
- target [N] semantic colors, normally 8–28
- visually distinct parts may receive different semantic IDs
- disconnected areas may share the same semantic color; do not bridge them
- background must remain a distinct non-playable class

This is a topology-authoring artifact, not final game art.
