# Final Artwork QA Prompt

Review master, semantic map, subject/void masks, cell boundary overlay and settled gem texture together.

Return PASS / REWORK / BLOCKED for:
1. Master visual quality
2. Semantic palette quality
3. Negative-space preservation
4. Cell shape quality
5. Connected-region readability
6. Settled gem material quality
7. Thumbnail readability
8. Production consistency

Reject if:
- cells occupy visible background gaps
- micro-cells dominate important areas
- the result reads as a visible square grid
- the result reads as an ordinary illustration rather than gem mosaic
- facial/subject identity is damaged
- topology crosses major semantic boundaries
